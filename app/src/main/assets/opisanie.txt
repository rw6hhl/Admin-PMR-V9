1. Главный экран
- **Жёлтый дисплей**:
  - Большая цифра в центре — текущий канал (от 1 до 8, буква «R» — репитер).
  - Цифры под ней — ваш ID (например, `111111`).
  - Число в левом нижнем углу — количество активных пользователей на канале.
  - Строка сверху (серая полоса) — IP-адрес сервера (если включено в настройках).
- **Кнопки**:
  - `MENU` — открывает экран настроек (сервер, параметры, справка).
  - `SCAN` (ранее CALL) — запускает режим сканирования.
  - `UP` / `DOWN` — переключение каналов вверх/вниз.
  - Кнопки `1, 2, 3, 4, 5` — ячейки памяти. Короткое нажатие загружает сохранённые настройки из ячейки, долгое нажатие (удержание) — сохраняет текущие настройки в ячейку. Активная ячейка подсвечивается оранжевой рамкой.
  - Зелёный/красный кружок в правом верхнем углу (если включено) — кнопка ВКЛ/ВЫКЛ питания.
- **Область передачи (нижняя часть)**:
  - Нажатие и удержание в нижней части экрана (PTT) — передача голоса. При удержании более 150 мс загорается красный индикатор.
  - Двойной быстрый тап по этой области — включает/выключает «Постоянную передачу».

2. Режим SCAN (Сканирование)
1. **Включение сканирования ячеек**: Нажмите на кнопку **SCAN**. Она подсветится красным ореолом. Программа начнет по кругу (с интервалом 0.5 секунды) загружать ячейки 1–5. Активная ячейка будет подсвечиваться оранжевой рамкой.
2. **Остановка на звуке (Скан ячеек)**: Как только на текущей ячейке появится звук, сканирование приостановится. Если звук пропадет более чем на 3 секунды, сканирование автоматически продолжится.
3. **Сканирование каналов внутри ячейки**: 
   - Пока идет сканирование ячеек, нажмите на любую цифру (**1, 2, 3, 4 или 5**) — выберется конкретная ячейка.
   - Затем нажмите **UP** (Вверх) или **DOWN** (Вниз). 
   - Программа начнет переключать каналы (1→2...→8→1) внутри параметров выбранной ячейки.
4. **Остановка на звуке (Скан каналов)**: При появлении голоса на каком-либо канале, сканирование замирает. Через 3 секунды тишины оно продолжается дальше.
5. **Передача (PTT) при сканировании**: Если во время сканирования вам нужно ответить, просто нажмите и удерживайте **PTT**. Сканирование полностью отключится, и вы будете передавать в текущем найденном канале.
6. **Выключение сканирования**: После отпускания PTT режим сканирования **автоматически выключается**.

3. Настройки (по кнопке MENU)
- **Настройки сервера** (скрытая секция): ввод `MyMailIndex` (ID), `Priznak_pmr`, портов (`PORT_prm`, `PORT_prd`) и IP-адреса сервера.
- **Настройки параметров** (скрытая секция):
  - `Постоянная передача` (двойной тап).
  - `Показывать list.txt` (имена в CALL).
  - `Запрашивать пароль` (при входе в режим админа).
  - `Симплекс` (отключает приём во время передачи).
  - `Показывать кнопку ВКЛ/ВЫКЛ`.
  - `Показывать IP сервера на главном экране`.
  - `Усилитель микрофона` (и ползунок усиления).
  - `АРУ` (автоматическая регулировка усиления).
  - `Усилитель выхода` (и ползунок громкости).
  - `Звук кнопок`.
- **Кнопки внизу**:
  - `Режим передачи` — выбор кодека (G711, PCM).
  - `Список` (только для админа) — открывает список абонентов.
  - `ЗАГРУЗИТЬ list.txt` — загрузка справочника имен.
  - `Логи` (только для админа) — просмотр системных логов.
  - `Хочу поделиться программой` — ссылка на форум.
  - `Описание работы программы` — показывает этот текст.
  - `ПРОВЕРИТЬ ОБНОВЛЕНИЯ` — проверяет наличие новой версии на GitHub и скачивает её.
  - `СОХРАНИТЬ ПАРАМЕТРЫ ЯЧЕЕК` — экспорт ячеек 1–5 в файл.
  - `ЗАГРУЗИТЬ ПАРАМЕТРЫ ЯЧЕЕК` — импорт ячеек из файла.
  - `СОХРАНИТЬ И ВЫЙТИ` — применяет настройки и возвращает на главный экран.

4. Список абонентов (только режим Админа)
- **`СПИСОК АБОНЕНТОВ`**: отображает ID, IP и статус блокировки пользователей.
- **Кнопка `ОБНОВИТЬ СПИСОК`** (внизу) — запрашивает у сервера актуальный список.
- **Кнопка `БАН/РАЗБАН`** (в каждой строке) — блокирует или разблокирует выбранного пользователя.
