Admin PMR — приложение для голосовой связи через сервер PMR.

НАЗНАЧЕНИЕ
Приложение предназначено для обмена голосовыми сообщениями по протоколу
PMR через UDP-сервер. Поддерживает два режима: обычный клиент (PMR Client)
и режим администратора (PMR Admin).

ОСНОВНЫЕ ВОЗМОЖНОСТИ
1. Голосовая связь в режиме PTT (push-to-talk).
2. Выбор каналов связи.
3. Просмотр списка участников канала.
4. Отправка вызова (CALL) — звуковой сигнал BELL.
5. Регулировка усиления микрофона и выхода, автоматическая регулировка усиления (АРУ).
6. Режимы «симплекс» и «дуплекс».

УПРАВЛЕНИЕ
- Кнопка CALL — отправить вызов в текущий канал.
- Кнопка PTT — удерживайте для передачи голоса. Короткое нажатие (менее 150 мс)
  отменяет передачу, длинное — включает отправку пакетов.
- Двойной тап по PTT — включение/выключение latch-режима (фиксация передачи).
- Кнопка LIST — открыть список участников канала.
- Меню → Настройки — параметры работы приложения.
- Меню → СПРАВОЧНАЯ ИНФОРМАЦИЯ — данное описание и ссылка на cqham.ru.

СЕРВЕР

Порты и параметры подключения задаются в настройках приложения.
