Android Admin PMR — описание работы

Версия: V13.7
Платформа: Android (minSdk 26, targetSdk 34)
Имя APK: app-v13.7.apk

1. Назначение

Программа Admin PMR предназначена для организации голосовой 
радиосвязи через интернет (UDP) с использованием сервера PMR. 
Приложение работает как клиент PMR или как администратор 
(при входе в скрытый режим по паролю). 
Передача и приём звука ведутся по протоколу G.711 (16 кГц). 
Поддерживается смена каналов, сканирование, ячейки памяти, 
работа с внешними кнопками (проводные и Bluetooth-наушники),
режим VOX (голосовое включение передачи) и режим 144-146 МГц.

2. Экраны программы

2.1 Главный экран

Отображает жёлтый экран с номером текущего канала, идентификатором (MyMailIndex), 
количеством активных пользователей и (опционально) IP-адресом сервера. 
Кнопки: MENU, SCAN (или LIST в режиме администратора), UP, DOWN, ячейки памяти 1-5, 
а также кнопка ВКЛ/ВЫКЛ питания (если включена в настройках). 
В нижней части экрана расположена область PTT (нажатие и удержание для передачи, 
двойной тап для постоянной передачи). 
По краям экрана добавлены дополнительные зоны PTT. 
Цвет канала меняется на тёмно-зелёный в режиме администратора.

2.2 Экран настроек

Содержит разделы «Настройки сервера» и «Настройки параметров». 
В настройках сервера вводятся MyMailIndex, Priznak_pmr, порты (PORT_prm, PORT_prd), 
IP-сервера. 
В настройках параметров находятся галочки: «Энергосбережение», «Включить VOX», 
«144 - 146 МГц», 
«Постоянная передача», «Показывать list.txt», «Запрашивать пароль», «Симплекс», 
«Показывать кнопку ВКЛ/ВЫКЛ», 
«Показывать IP сервера», а также поля усиления микрофона, АРУ, усиления выхода и порога VOX. 
Внизу расположены кнопки: «Режим передачи», «Список» (только для администратора), 
«ЗАГРУЗИТЬ list.txt», «Логи» (только для администратора), 
«Хочу поделиться программой», «Описание работы программы», «ПРОВЕРИТЬ ОБНОВЛЕНИЯ», 
«СОХРАНИТЬ ПАРАМЕТРЫ ЯЧЕЕК», «ЗАГРУЗИТЬ ПАРАМЕТРЫ ЯЧЕЕК», «СОХРАНИТЬ И ВЫЙТИ».

2.3 Экран списка абонентов

Доступен в режиме администратора. Отображает номер, идентификатор, 
IP-адрес и статус блокировки пользователей. 
Внизу расположена кнопка «ОБНОВИТЬ СПИСОК» для запроса нового списка с сервера. 
В каждой строке есть кнопка «БАН/РАЗБАН».

2.4 Экран логов

Просмотр системного журнала. Доступен только администратору.

3. Фоновый сервис

Запускается при старте приложения как foreground service. 
Выполняет работу UDP-сокета (PmrSocket), аудиодвижка (AudioEngine) 
и обработку широковещательных команд (PTT, VOX, сканирование). 
В строке состояния отображается постоянное уведомление.

4. Голосовой тракт

Передача: при нажатии PTT или срабатывании VOX микрофон захватывается, 
звук кодируется в G.711 и отправляется на сервер. 
Приём: входящие пакеты декодируются и воспроизводятся через аудиовыход.
 
Поддерживается усиление микрофона, АРУ, усиление выхода и выбор кодека (G.711, PCM).

5. Режимы и функции

5.1 Сканирование (SCAN)

Кнопка SCAN запускает сканирование ячеек памяти 1-5 с интервалом 0.5 с. 
При появлении звука сканирование приостанавливается; 
если звук пропадает более чем на 3 секунды, сканирование продолжается. 
Нажатие UP или DOWN во время сканирования переключает режим на сканирование каналов внутри выбранной ячейки.

5.2 Режим 144-146 МГц 

При включении этого режима ячейки памяти 1-5 фиксированно загружают 
MyMailIndex (144000, 144500, 145000, 145500, 146000) и канал 5. 
Кнопки UP и DOWN изменяют MyMailIndex с шагом 25, 
циклически переходя между границами 144000 и 146000.

5.3 VOX (голосовое включение передачи)

При включении VOX приложение постоянно анализирует уровень микрофона. 
Если уровень превышает заданный порог, передача включается автоматически. 
После 2 секунд тишины передача выключается. Работает с проводными и Bluetooth-наушниками.

5.4 Энергосбережение

При включении этой функции экран гаснет через 3 минуты бездействия. 
При появлении звука в канале экран включается и горит до пропадания звука (плюс 3 минуты). 
Программа продолжает работать в фоне.

5.5 Кнопки наушников

Поддерживается обработка кнопки проводных и Bluetooth-наушников (KeyEvent.KEYCODE_HEADSETHOOK).
Реализация аналогична экранной кнопке PTT (удержание и двойной тап).

5.6 Симплекс/дуплекс

При включённом симплексе передача блокируется, если в канале уже есть звук. 
Если передача начата на свободном канале, она не прерывается при появлении другого звука. 
В дуплексе передача разрешена в любой момент.

6. Проверка обновлений

По нажатию «ПРОВЕРИТЬ ОБНОВЛЕНИЯ» открывается страница с APK-файлами на GitHub. 
Пользователь может скачать новую версию вручную. 
Перед установкой новой версии старую нужно удалить.

8. Известные ограничения

Канал 6 (kanal=14, порт 16014) иногда не отвечает со стороны сервера.
При смене аудиоустройства может потребоваться перезапуск программы.
При установке новой версии поверх старой возможна ошибка подписи; 
рекомендуется удалить старую версию.
